🏛️ CCF Applicant Chatbot

Retrieval-augmented chatbot for Cornwall Community Foundation

✅ How to embed on your site

Add this script tag just before </body> on any page:

<script src="https://your-server.com/widget/embed.js"
        data-api-base="https://your-server.com"
        data-primary-color="#1E3A5F"
        data-position="bottom-right"
        data-title="Ask CCF"></script>

Or initialise manually:

<script src="https://your-server.com/widget/embed.js"></script>
<script>
  CCFChatbot.init({
    apiBase: "https://your-server.com",
    primaryColor: "#1E3A5F",
    position: "bottom-right",
    title: "Ask CCF"
  });
</script>

📋 Technical details

Backend FastAPI server (Python) with BM25 keyword search
Search engine Pure Python BM25 — no ML dependencies, runs on any server
Indexed pages 30 pages (27 HTML + 3 PDFs) covering grants, eligibility, FAQs, policies, annual accounts, and more
Re-index POST /reindex to re-crawl and rebuild the index
Data privacy No personal data logged. No cookies. No tracking.
Disclaimer Visible disclaimer reminds users to verify critical info

🚀 Deploying the server

On your server:

# Install dependencies
pip install -r requirements.txt

# Crawl the site
python crawl.py

# Build the index
python index.py

# Start the server
python server.py

# The server runs on http://0.0.0.0:8080
# Widget available at http://your-server:8080/widget/embed.js

⚠️ Known limitations

  • The chatbot can only answer questions based on the content it has indexed. If a page is missing from data/pages.txt, it won't know about it.
  • Dynamic content (JavaScript-rendered pages) is not crawled — the site's WordPress content is server-rendered, so this is fine.
  • PDF documents are now supported — add PDF URLs to data/pages.txt and they'll be extracted and indexed automatically.
  • The current fallback answer is template-based. For best results, configure an LLM API key in the server.
